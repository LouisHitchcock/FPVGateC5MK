See every pilot's signal, live

This page talks to an FPVGate C5MK receiver over USB and shows what it hears on up to eight 5.8 GHz channels, about a thousand times a second each. Use it to check a new receiver, find clear channels, set RotorHazard thresholds or watch a pass go through the gate.

  1. 1
    Flash C5MK onto your ESP32-C5Use the C5 flasher (Waveshare C5-Zero, XIAO ESP32-C5 and others). Fit a 5.8 GHz antenna.
  2. 2
    Plug the C5 into this computerUse its USB-C port and a data cable. Close RotorHazard, serial monitors and other tabs using the port first: only one program can have it at a time.
  3. 3
    Press Connect and pick the C5It shows as a USB JTAG/serial device. The browser remembers it, so next time the page reconnects on its own.
This browser can't use USB serial devices. Open this page in Chrome or Edge on a desktop or laptop.

Good to know

  • Nothing leaves your computer: the page runs entirely in the browser.
  • Connecting takes the receiver back from RotorHazard if RH was using it. Restart RH when you're done here.
  • The receiver doesn't transmit, so it's safe to use beside a race.
  • Readings are in dB relative to the C5's own noise; what matters is how far a pilot rises above the floor.
