# FPVGate brand assets

The receiver tools follow the dark design foundation at
https://fpvgate.xyz/styles.css (checked 19 October 2026): charcoal surfaces,
FPVGate blue, IBM Plex Sans / Mono and 3 / 5 / 8 px corner radii.
The shared implementation is `../brand.css`.

`fpvgate-logo.png` is the existing FPVGate mark from
https://fpvgate.xyz/logo-black.png. It is displayed inverted on the dark UI.

The IBM Plex fonts are unmodified Latin WOFF2 builds distributed by Google
Fonts, using the same families as the FPVGate website. They are bundled here
to avoid requiring an external font service while using the receiver tools.
The Sans file is variable (400–700); Mono is bundled at 400 and 500.

- Sans: https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxeKYY.woff2
- Mono regular: https://fonts.gstatic.com/s/ibmplexmono/v20/-F63fjptAgt5VM-kVkqdyU8n1i8q1w.woff2
- Mono medium: https://fonts.gstatic.com/s/ibmplexmono/v20/-F6qfjptAgt5VM-kVkqdyU8n3twJwlBFgg.woff2
