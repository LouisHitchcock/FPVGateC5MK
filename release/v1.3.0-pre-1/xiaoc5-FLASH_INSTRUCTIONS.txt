C5MK 1.3.0-pre-1 - xiaoc5

Use the ESP32-C5 USB port, not the S3. Back up first. esptool 5.1+.

python -m esptool --chip esp32c5 --port PORT --baud 921600 write-flash 0x2000 xiaoc5-bootloader.bin 0x8000 xiaoc5-partitions.bin 0xf000 xiaoc5-ota_data_initial.bin 0x20000 xiaoc5-firmware.bin

NVS at 0x9000 is not written; full erase removes settings. Power cycle afterwards.
